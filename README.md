# 🎸 XV Bass Pedal v6.0 (Custom Edition — iPad iOS 12 + Mac + Windows)

Plugin y App nativa de preamplificador Bi-Amp para bajo eléctrico:
- 📱 **iPad / iPhone (compatible desde iOS 12.0+, incluido iPad mini 2 con iOS 12.5.7)**: App nativa `.ipa` C++ de ultra-baja latencia (`Accelerate vDSP` ARM64) + versión AUv3 para GarageBand.
- 🍎 **macOS (Universal Apple Silicon + Intel)**: Audio Unit `.component` para Logic Pro, `VST3` y `App Standalone`.
- 🪟 **Windows 64-bit**: `VST3` + `App Standalone`.
- 🌐 **Navegador / Safari iOS 12+**: Versión Web / App de pantalla de inicio sin vencimiento.

## 📥 Descarga Directa de Instaladores Oficiales
Entrá a [**Releases (Última Versión)**](https://github.com/Somospopups/Plugin-Bass/releases/latest):
- 📱 **iPad mini 2 (iOS 12.5.7) y todos los iPad/iPhone (Sideloadly)**: `XV_Bass_Pedal_iPad_iOS12.ipa`
- 🎹 **iPad / iPhone con extensión AUv3 (GarageBand / AUM)**: `XV_Bass_Pedal_iPad_iOS12_GarageBand_AUv3.ipa`
- 🍎 **Mac (Logic Pro `.pkg`)**: `Instalar_XV_Bass_Pedal_Mac_Universal.pkg`
- 🪟 **Windows 64-bit (`.exe`)**: `Instalar_XV_Bass_Pedal_Windows_x64.exe`

## ☁️ Sincronización Automática de Presets (`xv_updates.json`)
Editá `xv_updates.json` directamente acá en GitHub (subiendo `"presetsRevision"` en `+1`) para actualizar o sumar canciones automáticamente en Mac, Windows y en el iPad mini 2 sin reinstalar.
